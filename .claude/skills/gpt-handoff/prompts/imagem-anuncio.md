# Prompt: imagem para anúncio

Preencha os colchetes antes de entregar ao usuário. Um prompt por criativo.

```
Gere uma imagem para anúncio no Instagram, formato [1080x1080 / 1080x1350 / 1080x1920],
sem nenhum texto na imagem (o texto será aplicado depois).

Produto: [NOME], um [FORMATO] para [AVATAR EM 1 FRASE].
Ângulo do anúncio: [ÂNGULO, ex.: a dor de X]. A imagem precisa fazer a pessoa parar de
rolar o feed em menos de 1 segundo e sentir [EMOÇÃO].
Cena: [DESCRIÇÃO OBJETIVA]. Ponto focal no centro-superior, área inferior com menos
detalhe para receber texto.
Paleta: predominância de [HEX] e [HEX], detalhe em [HEX].
Estilo: [fotografia realista com celular / ilustração / colagem]. Evitar aparência de
banco de imagens, rostos famosos, logotipos de terceiros, antes e depois corporal.

Entregue 4 variações com cenas diferentes para o mesmo ângulo.
```

Onde salvar: `projetos/<slug>/07-criativos/imagens/<angulo>-<hook>-v1.png` etc.
Claude aplica texto, logo e CTA via HTML/SVG e renderiza a versão final.
